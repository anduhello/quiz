# 心の番 · 内测体验站

五项人格/角色相似度测试的静态版本，供朋友直接打开体验，无需卡密、无需注册。

- 导航首页：https://anduhello.github.io/quiz/
- 魔法映照：https://anduhello.github.io/quiz/magic/
- 灵魂选修课：https://anduhello.github.io/quiz/soul-major/
- 庄园回声 · 求生者篇：https://anduhello.github.io/quiz/idv-survivor/
- 庄园回声 · 监管者篇：https://anduhello.github.io/quiz/idv-hunter/
- 费伦生活手札：https://anduhello.github.io/quiz/faerun/

## 说明

- 纯静态：只有 HTML/CSS/JS 与图片，无后端、无数据库、无卡密。
- 答案与进度保存在访问者本机 localStorage，换设备不同步。
- 本目录即发布源：`main` 分支根目录通过 GitHub Pages 发布。
- 更新流程：改完文件后 `git add -A && git commit -m "update" && git push`，Pages 会自动重建。
- 角色剧照、游戏素材版权归原权利方，仅作内测交流，不作商用。
